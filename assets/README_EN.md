# Tienkung 2.0 PRO D405 Hand Camera Mount Assets

This directory contains Intel RealSense D405 camera-mount references for Tienkung 2.0 PRO with Inspire 6-DOF dexterous hands. The mount is installed near the wrist/hand so the D405 can observe the thumb-index web area and grasping region. It is fixed with two M3 screws.

## Files

- `camera_holder_dual_hands_l.jpg`: left-hand mount reference photo.
- `camera_holder_dual_hands_r.jpg`: right-hand mount reference photo.
- `d405_usb.jpg`: example D405 USB connection to the AGX.
- `tirnkung_wrist_camera.STL`: wrist D405 camera mount STL model.
- `2hand_camera.STL`: dual-hand camera mount STL model.

## Installation Checks

Before teleoperation or data collection, check that the M3 screws are not too long, the hand and wrist can move without colliding with the mount or camera, and the camera cable has enough slack and strain relief.
